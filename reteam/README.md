# reteam — Your AI Real Estate Team

Sets up a team of AI assistants for your real estate business, each owning one job, organised like a real brokerage: lead qualifier, listing writer, comp analyzer, follow-up, CRM updater, market reporter, transaction tracker and more. They run on the tools you already pay for and never sleep, forget, or send the same message twice.

**[Download reteam.skill](https://github.com/FindingLand/claude-re-skills/raw/main/reteam/reteam.skill)** then install it in Claude: Settings, Capabilities, Skills, upload.
