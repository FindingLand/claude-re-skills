# newsdigest — Your Own Signal-Only News Briefing

Turns Claude into a personal news editor that works for your attention, not against it. You tell Claude the few topics and sources you actually care about. It searches across three windows (today, this week, this month), cuts the clickbait and the ten-articles-about-one-thing noise, and hands you a short list of headlines only. Say a number to get more on any one.

No feed, no doomscroll. When nothing important happened in your areas, it says so instead of padding the list. On first run it asks what you want to follow and where from, and can save it so it never asks again.

**[Download newsdigest.skill](https://github.com/FindingLand/claude-re-skills/raw/main/newsdigest/newsdigest.skill)** then install it in Claude: Settings, Capabilities, Skills, upload.
