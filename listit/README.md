# listit — Write Every Listing in 2 Minutes

Turns a few property details into a full set of listing content, in your voice and fair-housing safe: the MLS description, social captions per channel, an email blast, an open-house blurb, flyer text, and an SMS to your buyer list.

**[Download listit.skill](https://github.com/FindingLand/claude-re-skills/raw/main/listit/listit.skill)** then install it in Claude: Settings, Capabilities, Skills, upload.
