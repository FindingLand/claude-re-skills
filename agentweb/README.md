# agentweb — Your Own Real Estate Website, Free

Turns Claude into your website builder. Claude writes the whole static site (hero, bio, listings showcase, areas served, working lead form that emails you), keeps it in a free GitHub repo, and publishes it free on Netlify with your custom domain and HTTPS.

Running cost: $0 on the free tiers. You stop paying the monthly website-builder subscription, and you edit the site by just asking Claude.

**[Download agentweb.skill](https://github.com/FindingLand/claude-re-skills/raw/main/agentweb/agentweb.skill)** then install it in Claude: Settings, Capabilities, Skills, upload.
