# Free Claude Skills for Real Estate

Free, ready-to-install skills for Claude AI, built and battle-tested by [Finding Land](https://findingland.help). Each skill teaches Claude how to do one high-value real estate job for you.

## How to install a skill (1 minute)

1. Download the `.skill` file
2. In the Claude app go to Settings, then Capabilities, then Skills
3. Upload the file. Done: Claude now knows how to do the job
